#  AI Connector Plus

A FastAPI backend that integrates **real-time weather data** with **AI-powered summaries**.  
Built using **FastAPI**, **Open-Meteo API**, and **OpenAI API**.

---

## Features
- Get current weather for major cities
- Generate AI summaries for any text
- Combine both (weather + AI description)
- Caching layer with 5-minute TTL
- Fully async & production-ready
